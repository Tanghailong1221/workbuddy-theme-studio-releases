先在随心换里确认，

02 / 三步上手

不需要懂代码，
三步完成一次换肤。

整个过程在随心换中完成。软件会先检测连接状态；没有确认前，不会改动当前 WorkBuddy 的界面。

  1. 01

    启动并连接

    打开 WorkBuddy 后启动随心换。软件自动检查连接与兼容状态，也可以随时手动刷新。

    先检测，再开始
  2. 02

    挑选并微调主题

    在预设中选择喜欢的方向，切换欢迎页或对话页实时查看；需要时再改颜色、背景与品牌文案。

    预览不等于写入
  3. 03

    确认后应用

    点击“应用到 WorkBuddy”才会生效。之后可保存、导出、还原；客户端更新时也可先检查兼容性。

    支持还原与恢复

安装前须知

少一点猜测，多一点确定。

这是 WorkBuddy 官方软件吗？
不是。本工具为独立第三方界面个性化软件，不代表 WorkBuddy 及其关联方。
下载后的第一步是什么？
先启动 WorkBuddy，再打开随心换；连接状态与兼容性结果会显示在软件顶部。确认预览后才点击应用。
软件需要激活吗？
当前为免费公测版，不需要购买、激活码、账号或设备绑定。
软件能自动更新吗？
支持。Windows x64、x86 与 ARM64 版本会在软件内提示更新；确认后下载对应架构的安装包并自动完成升级。
