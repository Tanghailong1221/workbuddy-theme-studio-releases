01 / 开始使用

第一次连接 WorkBuddy

  1. 确认正在使用 WorkBuddy 个人版 Windows 桌面客户端，并先保存未发送的消息、资料库编辑和任务表单。
  2. 启动 SkinBuddy。顶部“启动自检”会检查 WorkBuddy 安装位置、运行状态和主题连接。
  3. 未启动时点击“启动 WorkBuddy”；已运行但未连接时，按提示确认“重启并连接”。
  4. 看到连接和兼容状态可继续后，再选择预设或进入编辑页。预览不会改变 WorkBuddy，只有点击“应用到 WorkBuddy”才会写入当前窗口。
先检测，再应用新版 WorkBuddy 未通过兼容检查时，不会被自动当作完全兼容。请先检查预览，只在确认后进行一次可回退试用。

02 / 主题与编辑

选择、预览并微调主题

在“预设”页选择主题卡片后，可按色调、是否带背景、收藏和关键词进一步筛选。需要改配色、标题或背景图时，进入“正在编辑”页；左侧预览会实时反映当前修改。

强调色
用于主按钮、选中态和重点提示。应与底色保持明显对比。
底色与文字色
决定大面积背景和可读性。深底配浅字，浅底配深字，并在实际 WorkBuddy 页面确认。
背景图
优先选择对话区域留白、来源清晰的静态图片；避免超高分辨率、动图和来源不明的文件。
动态背景
可在设置中随时暂停；系统开启“减少动态效果”时会自动关闭。

03 / 保存、导入与分享

保留自己的常用配置

确认效果后点击“保存主题”，保存、导入或另存的主题都会进入“我的主题”。在“导入、导出与分享”中可以复制分享码、导出完整 theme.json、粘贴分享码或从文件导入。

  • 分享码不包含背景图；需要完整迁移时请导出 theme.json。
  • Windows 本地数据位于 %LOCALAPPDATA%\WBThemeStudio。迁移电脑或重装前，可导出重要主题或备份该目录。
  • 删除主题只会删除本机主题记录，不会删除 WorkBuddy 的聊天、文件、项目或账号数据。

04 / 兼容、安全与恢复

页面异常时，优先恢复原生界面

“兼容性中心”会检查 WorkBuddy 版本、调试端口和页面结构。它是保护机制，不是错误页。

已验证兼容
可正常应用主题和开启自动恢复。
需要确认试用
先保存工作，只做一次可回退试用；异常时立刻还原。
安全模式
暂停注入和自动重放，让 WorkBuddy 保持原生界面，适合排查明显错位或可用性问题。
一键回滚
回到上一次成功应用的主题或原生状态。
出现白屏、严重卡顿或关键操作不可用依次执行“还原原生”→“进入安全模式”→“重新检测”。不要反复强制应用未验证版本，也不要修改 WorkBuddy 的 app.asar 或安装文件。

05 / 常见问题

快速排查

点击应用后没有变化
查看顶部连接状态，确认未处于安全模式；必要时重启并连接 WorkBuddy 后再次应用。
WorkBuddy 更新后出现局部样式异常
先还原原生并进入安全模式，复制诊断信息后再反馈。不要下载来源不明的“补丁”。
启动后没有自动换肤
检查“自动恢复上次主题”是否开启，并确认不是从已固定的旧任务栏图标启动。
主题导入失败
仅使用分享码或合法的 theme.json。检查颜色是否为 #RRGGBB，并确认分享码没有截断。
